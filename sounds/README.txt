Sounds folder
=============
Drop .wav / .mp3 / .ogg files here (or in the per-user folder that "Open folder" in her
settings panel opens) and they appear in the Sounds section of the panel, so you can
assign any of them to any event.

Bundled clips (girl-*.mp3)
--------------------------
"Cheerful girl" everyday-line voice set from 効果音ラボ / Sound Effect Lab
https://soundeffect-lab.info/sound/voice/line-girl1.html
Free for personal and commercial use, no credit required (see their 利用規約).
They ask that the files not be redistributed as a sound library on their own.

  girl-ehehe / ufufu / ufufu2 / ahaha / ahaha2 / kusukusu / kyahaha   laughs
  girl-yattaa / yattane / banzai / ureshii / wow / hee / oo / oo2 / o   happy, impressed
  girl-uu / uu2 / u / ueeen / uwaan / hikku / shikushiku / sonnaa       sad, crying, pouting
  girl-hyaa / uwaa / kyaaa / gyaaa / a / ee / ee2 / shock / giku / are  surprise, scream, startled
  girl-n / nn / hai / haihai / yaa / yoho                                nods, hello
  girl-akubi / munya / suyasuya                                          yawn, sleepy
  girl-nyaa / mukka / ganbatte / gomenne                                 cat, grumpy, "do your best", "sorry"
